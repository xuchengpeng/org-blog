#+TITLE: Berkeley Mono 在 Windows Emacs 中的显示问题
#+AUTHOR: Chuck
#+DESCRIPTION: Berkeley Mono 在 Windows Emacs 中存在斜体、下划线等显示问题，与在 Linux 中显示不一致。
#+FILETAGS: :Emacs:BerkeleyMono:Linux:Windows:
#+DATE: <2026-11-26 Thu 13:06>

在 Windows Emacs 中将默认字体设置为了 Berkeley Mono ，结果发现 italic 样式还是显示为正体，并且 underline 样式的有差不多 2px 看起来很粗，而在 Linux Emacs 中相同字体大小都没碰到这两个问题。

第一个问题的原因，Windows 的 GDI 字体注册（RIBBI 规则）[fn:ribbi]把 Berkeley Mono 的斜体注册成了独立字族 Berkeley Mono Oblique ，所以默认字族设置为 Berkeley Mono 时，italic 样式找不到默认字族的斜体，回退到正体显示。所以需要修改字体配置 Family Name (ID 1) 为 Berkeley Mono 和 Subfamily Name (ID 2) 为 Italic 或 Bold Italic 以符合 RIBBI 规范才行。

第二个问题的原因，字体文件 post 表的 underlineThickness （下划线粗细）值为 100 ，在 Windows Emacs 中 GDI 的 otmsUnderscoreSize 已按字号缩放并四舍五入后就是 2px ，而在 Linux Emacs 中的算法是向下取整就是 1px 。所以需要修改字体配置 underlineThickness 为 50 时就能和 Linux Emacs 保持一致。

需要注意的是，Emacs 的主干当前重构了绘制逻辑，引入了 =underline-line-scaling-flag= , =overline-line-scaling-flag= 和 =strike-through-line-scaling-flag= 来控制是否随字号大小来计算粗细，默认配置为 nil 时固定粗细为 1px ，在 Emacs 31 及以前的版本没有这个功能。

* Footnotes

[fn:ribbi] GDI 的 RIBBI 规则只认 Regular / Italic / Bold / Bold Italic 四种子族。
